# Working on mstack

Read `README.md`, `MEMORY.md` and `docs/STRUCTURE.md` before making changes.
When resuming, read `docs/HANDOFF.md` for the session handoff. The agreed
skill roots are `workflow/`, `orchestrator/` and `tracker/`. Detailed contents
remain to be drafted; planning files do not authorize installation/activation.

Keep material new decisions, facts, open questions and gotchas in `MEMORY.md`
when they are not already in lasting project guidance. Distinguish confirmed
decisions from proposals and link maintained specifications instead of copying
them. Promote stable guidance deliberately, not every temporary log entry.

Keep `legacy/backlog/` unchanged during architecture review. Its SKILL.md and
references are historical input, not operating instructions for this repo.
Do not install skills, run an orchestrator, alter timers, merge existing PRs, remove the
original backlog, or change deployment configuration as part of bootstrap.

Keep lifecycle validity separate from execution authority and harness tools.
Authoring discussion and roadmap context stay in planning notes, not the
distributed skill instructions or concrete adapter references.
Do not publish private workplace material, credentials or environment config.
Preserve the imported history; do not rewrite or force-push published history.
